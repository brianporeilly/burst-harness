MCP servers

Servers a session's or task's agent can connect to, over HTTPS. New sessions and tasks get the ones on by default, and their forms show every one here to pick from. A server's key goes in the Credentials: NAME_API_KEY for a bearer token, or NAME_BASIC_AUTH as user:secret (not encoded) for a server that takes Basic auth, such as an Atlassian personal API token. The gateway adds it. Those from the configuration (HARNESS_MCP) can be turned off by default, or replaced by one of the same name.

Job repos

Git repos of jobs, beside the orchestrator's job directories. Each is synced every few minutes, or now with Sync, and its jobs are read from one commit at a time; a run records the commit it ran from. Nothing is written back. A private repo is read with the credential named (JOBS_GIT_TOKEN unless you name another): a token that can only read it. Those from the configuration (ORCHESTRATOR_JOB_REPOS) are changed there.
